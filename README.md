# Recycling Bank

**A Smarter Way to Recycle Electronic Waste**

## About the Project

Recycling Bank is a web-based marketplace designed to make electronic waste recycling more accessible. The platform brings together recyclable materials, product listings, and recycling-related services in one place, offering a streamlined digital experience for individuals and organizations.

The project combines e-commerce functionality with a sustainability-focused concept to encourage responsible electronic waste management.

## Features

- **Marketplace:** Browse available materials and product listings.
- **Product Details:** Explore product information and descriptions.
- **Shopping Cart:** Manage selected items before checkout.
- **User Registration:** Access the account creation interface.
- **Checkout:** Navigate the checkout interface.
- **Arabic & English:** Language support across selected sections.
- **Responsive UI:** A layout designed for different screen sizes.

## Built With

- React
- TypeScript
- Shopify Hydrogen
- Tailwind CSS
- Vite
